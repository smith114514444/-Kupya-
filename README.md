## ✨ 特色亮点

- 🧸 **自主移动**  
  库皮亚会在桌面上自由散步、闲逛，偶尔发呆。

- 📺 **内置电视系统**  
  没事的时候它会自己放置小电视看视频！你可以把自己喜欢的 **ogv** 格式的视频放入 `video` 文件夹，库皮亚会随机播放。  
  *鼠标放在电视机上滑动滚轮可调节音量*

- 🎨 **可自定义贴纸**  
  把贴纸图片放入 `sticker` 文件夹，在装扮菜单中装饰库皮亚。  
  *鼠标滚轮 = 调整贴纸大小*  
  *鼠标侧键 = 旋转贴纸* （自定义按键即将补全）

- 🎭 **好感度剧情 & 角色对话（v0.1.4.2 新功能）**  
  角色之间会主动发起对话 —— 库皮亚会谈论德比，德比也会自我闲聊。  
  （旧版本好感度剧情为封锁版，完整对话版需加入内群获取；新版本已逐步开放基础对话）

- 🐕 **德比登场（v0.1.4.0）**  
  德比会挣脱束缚在桌面上四处游荡，被库皮亚追时会惊慌逃跑！

- 🛠️ **完全开源 · Godot 架构**  
  基于 Godot 引擎开发，代码结构混乱，我就不信有人能二次创作或学习桌面宠物实现逻辑（千万别学，小心变成屎山大王）。

## 🖥️ 运行要求

- **操作系统**：Windows（7 / 10 / 11）  
- **需要安装.NET10SDK** —— 下载后直接双击 `Kupya.exe` 即可运行。

## 📦 下载与运行

1. 前往 [Releases](../../releases) 页面下载最新版本压缩包（当前为 v0.1.4.2）。
2. 解压到任意文件夹（**请务必在解压后的文件夹内运行程序**，以保证视频/贴纸资源正常读取）。
3. 双击 `Kupya.exe` 启动。
4. 享受与库皮亚的桌面时光 🎉

## 🎮 交互指南

| 操作对象 | 交互方式 | 效果 |
|---------|----------|------|
| 电视机窗口 | 鼠标滚轮 | 调节音量 |
| 贴纸 | 鼠标滚轮 | 放大/缩小 |
| 贴纸 | 鼠标侧键 | 旋转角度（自定义按键即将支持） |
| 库皮亚本体 | 拖动/点击 | 拖拽移动 / 唤醒（晚上10点后可能睡觉） |
| 库皮亚本体 | 拖至屏幕最右侧 | 藏在屏幕边缘露出小脑袋 |
| 电视/德比 | 扔出屏幕 | 清除（飞行德比会飞回，建议用对话清除） |

## 📁 自定义内容

你可以轻松为库皮亚增加新内容：

- **视频**：把 `.ogv` 或其他 Godot 支持的视频文件放入 `video` 文件夹，电视机会自动识别并随机播放。
- **贴纸**：把图片文件（`.png`）放入 `sticker` 文件夹，即可在桌宠界面生成可调节的贴纸。
