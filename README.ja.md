## ✨ 特徴

- 🧸 **自律移動**  
  クピャがデスクトップ上を自由に歩き回り、たまにぼんやりします。

- 📺 **内蔵テレビ**  
  暇なときは小さなテレビを置いて動画を再生！お気に入りの **ogv** 形式の動画を `video` フォルダに入れると、ランダムに再生されます。  
  *テレビの上でマウスホイール → 音量調節*

- 🎨 **カスタムステッカー**  
  ステッカー画像を `sticker` フォルダに入れ、着せ替えメニューからクピャをデコレーションできます。  
  *マウスホイール = ステッカーのサイズ変更*  
  *マウスサイドボタン = ステッカー回転* （カスタムキー設定は近日対応）

- 🎭 **好感度ストーリー＆キャラクター会話（v0.1.4.2 新機能）**  
  キャラクター同士が自発的に会話を始めます — クピャがドビーについて話したり、ドビーが自分と会話したりします。  
  （旧バージョンでは好感度会話はロックされていました。完全版は内部グループでのみ提供されていましたが、新バージョンで基本的な会話が徐々に開放されています）

- 🐕 **ドビー登場（v0.1.4.0）**  
  ドビーが束縛を振り切りデスクトップ上をうろつき、クピャに追われると慌てて逃げ出します！

- 🛠️ **オープンソース · Godot アーキテクチャ**  
  Godot Engine で開発されています。コード構造はめちゃくちゃで、誰も二次創作やデスクトップペットの仕組みを学べないと思います（絶対にやらないでください、スパゲッティコードの王者になりますよ）。

## 🖥️ 動作要件

- **OS**：Windows（7 / 10 / 11）対応  
- **.NET 10 SDK をインストールしてください** —— その後、`Kupya.exe` をダブルクリックするだけで実行できます。

## 📦 ダウンロードと実行

1. [Releases](../../releases) ページから最新のアーカイブ（現在 v0.1.4.2）をダウンロードします。
2. 任意のフォルダに解凍します（**動画・ステッカーリソースを正しく読み込むため、必ず解凍したフォルダ内でプログラムを実行してください**）。
3. `Kupya.exe` をダブルクリックして起動します。
4. クピャとのデスクトップライフをお楽しみください 🎉

> ⚠️ バグを発見したら、Issue を立てるか、下記の連絡先までお知らせください。

## 🎮 操作ガイド

| 対象 | 操作 | 効果 |
|------|------|------|
| テレビウィンドウ | マウスホイール | 音量調節 |
| ステッカー | マウスホイール | 拡大/縮小 |
| ステッカー | マウスサイドボタン | 回転（カスタムキー設定は近日対応） |
| クピャ本体 | ドラッグ / クリック | 移動 / 夜間はクリックで起こせる |
| クピャ本体 | 画面右端までドラッグ | 端に隠れて小さな頭を出す |
| テレビ/ドビー | 画面外に投げる | 消去（飛んでいるドビーは戻ってくるので、会話での消去を推奨） |

## 📁 カスタムコンテンツ

簡単にコンテンツを追加できます：

- **動画**：`.ogv` または Godot がサポートする形式の動画を `video` フォルダに入れると、テレビが自動認識してランダム再生します。
- **ステッカー**：画像ファイル（`.png`）を `sticker` フォルダに入れると、デスクトップペット上でサイズ変更可能なステッカーが生成されます。

## ⚠️ 重要な注意事項

- **v0.1.4.2 では必ずセーブデータを削除してください**（パスは上記参照）。将来のバージョンでは互換性を確保する予定です。
- 夜22:00から朝7:00まで、クピャは眠ることがあります。何度もクリックすると起こせます。
- クピャを画面右端までドラッグすると、端に隠れて小さな頭を出します。しばらくマウス操作がないと自分から出てきます。
- テレビの上でマウスホイールを回すと音量調節。ステッカーはホイールでサイズ変更、サイドボタンで回転（カスタムキー設定は近日対応）。
- テレビやドビーが邪魔になったら画面外に投げて消去できます（飛んでいるドビーは戻ってくるので、会話から「消去」を選ぶのがおすすめです）。

## 🐛 既知の問題

- ドビーが逃げるとき画面端でたまに引っかかる → 次バージョンで修正予定。
- タスクバーアイコンを非表示にしても、ソフト再起動で元に戻る → 後日最適化。
- 顔位置エディターでアニメーション切り替え後、【リセット】をクリックしてからパラメータ調整しないと座標がずれることがある。
